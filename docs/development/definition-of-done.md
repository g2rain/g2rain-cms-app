# 完成定义

需求完成至少满足：

- 范围和验收条件已记录，CMS 前端与 `g2rain-cms` 后端职责明确。
- 页面正常处理加载、空数据、成功、失败、无权限和重复提交。
- 独立/集成模式的影响已评估；实例资源可正确卸载。
- 路由、资源、i18n、环境和部署文档随实现同步。
- 未扩大架构偏差；必要偏差已登记。
- 未引入 Token、私钥、真实凭据或生产敏感信息。
- `npm run build` 通过；缺少自动化测试的部分已列出人工验证证据。
- `git diff --check` 通过，修改范围不包含无关业务代码或生成产物。

涉及生成器时，还需记录输入表、开关、覆盖范围与人工审查结果；涉及资源配置时明确 API endpoint 是否生成。
