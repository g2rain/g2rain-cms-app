# 需求索引

本目录用于保存可验收的 CMS 前端需求。每个需求单独建立 Markdown 文件，建议名称为 `YYYYMMDD-short-name.md`。

## 模板

```markdown
# 需求标题

## 背景与目标

## 范围

- 包含：
- 不包含：

## 用户与场景

## 业务规则

## 接口与数据

## 权限与安全

## 独立/集成模式影响

## 验收条件

- [ ] 可观察、可复现的结果

## 验证计划

## 风险与回滚
```

需求应明确前端交互与 `g2rain-cms` 服务端规则的边界。需要跨仓库改动时列出仓库、契约和发布顺序，不以模糊描述默认扩大范围。
